# 狮山智生活 — 微信小程序 MVP

这是一个用于需求验证的原生微信小程序演示版，覆盖：

- 校园电话卡套餐选购、模拟支付、实名激活与进度展示
- 电瓶车浏览、详情、模拟在线支付与校内配送
- 校园车辆牌照办理辅助：平台购车免费，自带车辆模拟收取49元服务费
- 订单列表与基础售后
- 学生身份模拟认证
- 本地数据持久化

## 如何运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 选择本目录 `campus-go-mvp`。
4. AppID 可使用测试号；项目已配置 `touristappid`。
5. 点击编译即可体验。

## 演示范围

当前版本使用本地模拟数据，不连接真实校方、实名或微信支付接口，也不会产生真实交易。预约、校园卡申请和售后记录保存在微信开发者工具的本地缓存中。

项目同时包含一个零依赖模拟 API 服务，位于 `server/`。它提供商品、校园卡申请、订单和售后接口，便于下一步把本地数据替换为联网数据。使用 Node.js 18+ 进入该目录后运行 `npm start` 即可启动；运行 `npm test` 可执行接口测试。

服务启动后，在浏览器访问 `http://localhost:3000/admin` 可以打开“狮山智生活”运营管理端。

## 建议演示路径

1. 首页 → 校园牌照辅助 → 填写并提交需求。
2. 首页 → 校园电话卡 → 填写咨询预约。
3. 首页 → 电瓶车 → 选择车辆 → 模拟支付和校内配送。
4. 订单 → 查看订单 → 提交售后。
5. 我的 → 模拟学生认证、拨打电话或复制客服微信。

## 商家资金账户

商家工作台（`pages/merchant/index`）的「资金账户」面板按后端分账状态机展示钱的位置：

`支付成功 → 交付核验 → 账期 → 申请提现 → 平台审核打款`

- 顶部显示可结算余额、平台服务费率与账期天数
- 下方分别列出待交付核验、账期中、已结算，以及仅在有金额时出现的提现待审核、售后冻结与已冲销
- 「最近分账」每条记录标注当前阶段（待交付核验/账期中/可结算/售后冻结/已结算/已冲销）和下一步提示，例如「09/12 后可结算」
- 「申请提现」按钮：可结算金额达到起提门槛且收款账户完整时可点击，确认后提交提现申请；不满足条件时按钮置灰并显示具体原因（金额不足、账户未配置、已有待审核申请）
- 「提现记录」列出最近 3 笔提现单及其状态（待审核/已打款/已驳回/已关闭），驳回会带上平台填写的原因

商家不能自己确认到账，只能提交申请，由平台在管理端「商家提现」页审核后打款。账期天数与起提门槛由管理端运营设置控制，详见 `server/README.md` 的「商家分账与账期」「商家提现申请与平台审核」。

## 履约超时预警

后端内置运营巡检定时任务，按管理端「运营设置」里的时限逐条扫描进行中的业务，把逾期风险变成可认领的预警工单，不再依赖有人打开管理端才发现超时。

`即将超时 → 已超时 → 已认领 → 自动关闭`

- 覆盖订单交付、电话卡激活、话费到账、宽带核验、牌照办理、售后响应与解决、提现审核、咨询线索跟进共 9 条规则
- 每条规则区分责任方：商家负责交付与售后，平台负责办理类与资金审核
- 业务状态推进后，下一轮巡检会自动关闭对应预警，无需人工销单
- 管理端「超时预警」页展示待处理/已超时/已认领统计、上次巡检时间，可手动触发巡检、认领预警并跳转到对应业务页
- 商家工作台（`pages/merchant/index`）的「履约提醒」卡片展示属于自己的未关闭预警和剩余时间，平台负责的条目不会出现在商家端

规则时限、巡检间隔的具体字段与接口说明见 `server/README.md` 的「运营巡检与超时预警」。

## 商家服务分

平台会根据按时交付、售后响应、售后满意、评价星级和差评处理五个维度计算商家服务分，并把结果用于商品曝光、上新复核和商家整改：正常商家自主经营，限流商家新增商品需平台复核，低分商家暂停上新。商家工作台和商品详情页均会展示服务分，管理端提供人工调分、待复核商品和变更日志。完整规则与接口见 `server/README.md` 的「商家服务分与平台处置」。
